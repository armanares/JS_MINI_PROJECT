# JS_MINI_PROJECT

This repository contains four beginner-friendly JavaScript projects that I built while learning DOM manipulation and JavaScript fundamentals. These projects helped me understand how JavaScript interacts with HTML and CSS to create interactive web pages.

## Projects

### 🎨 Color Changer

A simple project that changes the background color when a color button is clicked.

**Concepts Used:**

* DOM Manipulation
* Event Listeners
* CSS Styling with JavaScript

---

### ⚖️ BMI Generator

A BMI (Body Mass Index) calculator that takes height and weight as input and displays the BMI along with its category.

**Concepts Used:**

* Form Handling
* User Input
* Conditional Statements

---

### 🕒 Digital Clock

A live digital clock that displays the current time and updates every second.

**Concepts Used:**

* Date Object
* `setInterval()`
* DOM Updates

---

### 🎯 Guess the Number

A fun number guessing game where the user has to guess a randomly generated number within a limited number of attempts.

**Concepts Used:**

* Random Numbers
* Loops & Conditions
* DOM Manipulation
* Game Logic

## Purpose

I created these projects to practice JavaScript basics, especially DOM manipulation, events, functions, and working with user input.
